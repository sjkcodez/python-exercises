# Control Flow Statements Exercise

1. Write a Python program to find those numbers which are divisible by 3 between 10 and 30 (both included).

2. Write a Python program to find those numbers which are divisible by 7 and multiples of 5, between 1500 and 2700 (both included).

3. Write a Python program to find numbers between 100 and 400 (both included) where each digit of a number is an even number.

4. Write a Python program to count the number of even and odd numbers in a series of numbers

5. Write a Python program to sum two integers.

6. Write a Python program to calculate the sum and average of n integer numbers (input from the user). Input 0 to finish.

7. Write a Python program to create the multiplication table (from 1 to 10) of a number.
