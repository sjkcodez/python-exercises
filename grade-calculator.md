
# Grade Calculator

### Objective:
Create a program that determines and displays a student's grade based on their numerical score.   

### Requirements:
Create a variable named marks to store the student's score.   
Implement a conditional structure to assign grades based on the following scale:  
80 - 100: Grade A   
70 - 79: Grade B+   
60 - 69: Grade B   
50 - 59: Grade C   
40 - 49: Grade D   
30 - 39: Grade E   
0 - 29: Grade F   

If the value of marks falls outside the 0 to 100 range, the program must display "Invalid range".   
Expected Test Outputs:If marks is 88, the program should output: "Grade A"   
If marks is 75, the program should output: "Grade B"   
If marks is 42, the program should output: "Grade E"   


__Hint:__ Use if...elif statements
