# Conditional Statements Exercise

Write a program that verifies a passenger's flight ticket based on a numeric code entered by the user.   
The program should prompt the user for an input and output the correct Ticket Status and Seating Class according to the following rules:   
- If the user enters 3, the ticket is Normal and they should go to Economy class.
- If the user enters 2, the ticket is VIP and they should go to Business class.
- If the user enters 1, the ticket is VVIP and they should go to Royal class.
- If the user enters any other value, the program should display an error message: "Invalid input!".
